# FestVisuals

Локальный лаунчер Minecraft: Java Edition на Rust с интерфейсом в браузере. Устанавливает выбранную версию Minecraft, актуальный стабильный Fabric Loader и выбранные совместимые моды Fabric API, Sodium, Iris и Visuality через Modrinth. Версии Minecraft берутся из официального манифеста Mojang. Файлы модов проверяются по SHA-1; лаунчер удаляет только файлы, которыми управляет сам.

## Запуск

Нужны Rust (актуальный stable), Cargo, Java подходящей для выбранной версии Minecraft версии и интернет. Например, для современных версий Minecraft может потребоваться Java 25 — проверяйте требования выбранной версии. Java автоматически не устанавливается.

```sh
cargo run --release
```

Откройте **http://127.0.0.1:3210** на том же компьютере. Интерфейс встроен в исполняемый файл, отдельная папка `web` для запуска не нужна. Порт доступен только локально. Настройки и игровые файлы находятся в системном каталоге данных пользователя `FestLauncher` (`%LOCALAPPDATA%` на Windows, `~/.local/share` на Linux). Каждая версия имеет отдельную игровую папку в `minecraft/instances/<версия>`.

При первом запуске загрузка игры и ресурсов может занять время. Состояние и ошибки отображаются внизу главной страницы. Если мод не поддерживает выбранную версию, отключите его или выберите другую версию. Для Iris нужен отдельно установленный пользователем шейдер-пак. В настройках можно указать путь к Java и максимальный объём ОЗУ.

## Сборка Windows EXE

На Windows с установленным актуальным Rust выполните в корне проекта:

```powershell
cargo test --release
cargo build --release
```

Результат: `target\release\fest-launcher.exe`. Его можно запускать отдельно: окно консоли должно оставаться открытым, пока работает лаунчер. При запуске автоматически откроется браузер; если этого не произошло, откройте `http://127.0.0.1:3210` вручную. Для игры отдельно требуется совместимая Java и интернет.

Также добавлен ручной workflow **Build Windows EXE**: после публикации ветки в GitHub его можно запустить во вкладке Actions и скачать артефакт `FestVisuals-Windows`.

## Ограничения

- Вход только с локальным ником (offline account), без Microsoft-авторизации; серверы, требующие лицензионную авторизацию, не поддерживаются.
- Для запуска нужна локальная графическая среда; веб-страница сама по себе не запускает игру на удалённом устройстве.
- Java не скачивается автоматически; ошибки запуска и несовместимости доступны в статусе и игровом `logs/latest.log`.
- Совместимость Fabric и модов зависит от опубликованных версий. Наличие версии 26.2 в списке не гарантирует доступности каждого мода.

Ядро установки и формирования команды: [mc-launcher-core](https://github.com/Star-tears/mc-launcher-core). Метаданные: [Fabric Meta](https://meta.fabricmc.net/) и [Modrinth API](https://docs.modrinth.com/api/). Визуальный подход вдохновлён полупрозрачными панелями и скруглениями современных интерфейсов; код Telegram не копируется.

## Демо-аккаунт

Экран входа и регистрации — только демонстрация: данные не отправляются на сервер, аккаунт не создаётся, пароль не сохраняется и не проверяется. Не вводите настоящий пароль. Имя демо-сессии хранится только в `sessionStorage` текущей вкладки и не меняет игровой ник в настройках. Кнопка гостя сбрасывает демо-сессию. Авторизация Minecraft/Microsoft не реализована.
